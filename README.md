# ASCII ボックス ライン 作図 ツール

ASCII罫線文字（+, -, |, ┌, ┐, └, ┘, ─, │, ├, ┤, ┬, ┴, ┼ 他）でボックス・ダイアグラムを描くテキストエディタ。

## 機能
- 等幅フォントのテキストエリアエディタ
- 文字パレット: ASCII / 単線 / 二重線 / 矢印 / その他グループ（クリック挿入）
- プリセット6種: 単純ボックス・二重線ボックス・ダッシュ線・テーブル・ツリー図・フロー図
- 幅・高さ指定のブランクグリッド生成
- 全選択・全コピー（Clipboard API）・クリアボタン
- Tab キーで2スペースインデント
- LocalStorageで編集内容を自動保存
- 下部プレビューエリア（select-allで即コピー可）

## 技術
- Vanilla JS + Tailwind CSS CDN
- localStorage（エディタ内容の永続保存）
- Clipboard API（非対応時は execCommand fallback）
